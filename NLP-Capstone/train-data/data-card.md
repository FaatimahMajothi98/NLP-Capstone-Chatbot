# Data Card for human_chat.txt


### Content
The data corpus contains labelled chat data with Human 1 and Human 2 in an ask-reponse manner.
Each odd row with the `Human 1` label is the initiator of the chat and each even row with the `Human 2` label is the response.
Data after Human x: is the chat data which can be preprocessed to remove the label part.


### About this file

This dataset is a corpus compiled from Meena chat, Mitsoku chat and a human chat corpus.
Each line is a labelled chat by either Human 1 or Human 2 in reply-response fashion.
The corpus contains relevancy pertaining to subject and conversation related to particular topic in flow of conversation.


**Source: [Kaggle](https://www.kaggle.com/datasets/projjal1/human-conversation-training-data/data)**
