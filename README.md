# NLP-Capstone-Chatbot
**By Faatimah Majothi**

### Overview:
This project aims to use NLP (Natural Language Processing) techniques to build a data-driven chatbot trained on a corpus of real human conversation data, with the purpose of holding a simple conversation. The project was created as a capstone for the [Data Scientist: Natural Language Processing Specialist Career Path](https://www.codecademy.com/learn/paths/data-science-nlp) on Codecademy.

### Scope:
- Import python libraries and initalise workflow.
- Prepare and preprocess corpus data.
- Establish conversation questions and compare with user input.
- Create a loop of questions and connected answers for conversation.
- Test and run a complete mini chatbot.
